# Breadcrumb

展示页面层级，当前页使用明确的导航语义。

从 `aig-ui/breadcrumb` 导入，并在宿主导入 `aig-ui/styles.css`。公共类型和默认值见 breadcrumb.tsx，可编译示例见 breadcrumb.stories.tsx。

支持原生属性、className、style 和 ref；主题通过 --aig- 语义 Token 设置。

当前为实验性 alpha，完整浏览器与发布边界见 docs/progress.md。

方案 2.0 线框视觉：当前项使用玫瑰发丝下划线。公共样式保留键盘、禁用、错误和长文本的适用行为；静态文字采用自然字距，动态装饰遵循系统减少动态效果设置。
