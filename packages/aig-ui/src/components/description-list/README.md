# DescriptionList

使用 dl、dt、dd 展示标签和值，支持长标识与响应式分列。

从 `aig-ui/description-list` 导入，并在宿主导入 `aig-ui/styles.css`。公共类型和默认值见 description-list.tsx，可编译示例见 description-list.stories.tsx。

支持原生属性、className、style 和 ref；主题通过 --aig- 语义 Token 设置。

当前为实验性 alpha，完整浏览器与发布边界见 docs/progress.md。

视觉表现：字段名称与内容通过对齐、字重和间距建立阅读层级。 动态装饰遵循系统减少动态效果偏好。
