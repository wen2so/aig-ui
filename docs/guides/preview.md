# 组件预览指南

更新日期：2026-09-14。预览包含 50 个组件、AigProvider 主题作用域、5 个 Registry 页面组合、1 个视觉样板及可交互示例。运行 `pnpm preview`，打开[组件总览](http://127.0.0.1:5173/)；[按钮](http://127.0.0.1:5173/?component=Button)、[折叠面板](http://127.0.0.1:5173/?component=Accordion)、[主题作用域](http://127.0.0.1:5173/?component=AigProvider)和[加载序列](http://127.0.0.1:5173/?component=LoadingSequence)支持地址直达。

## 页面内容

| 区域           | 内容                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| 顶部导航       | 组件、动效、页面组合、主题定位到总览对应分组；支持重复定位、地址直达与浏览器历史                          |
| 搜索与左侧目录 | 中文用途和组件名搜索、十类组件目录；当前组件自动进入目录可见区域                                          |
| 全局主题       | 顶部唯一入口，统一选择品牌色、SVG、正文与标题字体、等宽字体、材质、密度与环境动效，包含接入代码与恢复默认 |
| 组件示例       | 独立状态、重置、可展开和复制的源码                                                                        |
| API            | 当前源码的公开属性、常用原生属性、组合部件、默认值、必填信息与相关数据类型                                |
| 使用说明       | 正常排版的组件 README、键盘与状态约定                                                                     |
| 本页目录       | 平滑定位示例、API 与说明                                                                                  |

Button 提供统一层级、状态对照、尺寸和自定义加载 SVG。品牌与字体参数集中在全局主题抽屉中，页面切换后继续沿用，并同步到加载图形和浮层。颜色、品牌图形与字体使用公共接口，普通页面和嵌套作用域可复用。Provider 的属性表与数据类型随 AigProvider 组件文档提供，接口细节见[品牌自定义](theme.md)。

正文与标题沿用 reference/404.html 的 Inter 和微软雅黑，代码与编号采用 JetBrains Mono。预览站本地加载字体文件。新增[视觉样板](http://127.0.0.1:5173/?component=visual-study)，集中展示编辑、保存确认、危险操作与完整加载交接。

## 动效与导航

目录缩略图与普通控件保持静态，详情页展示实际交互；加载和进行中的任务保留持续运动。按钮族共用轮廓。折叠面板、示例源码和文档切换采用连续过渡，页内定位与组件目录回顶使用平滑滚动。顶部导航回到总览并定位对应分组，搜索和分类筛选随导航恢复；重复点击同一分类仍会重新定位。左侧目录独立滚动，正文位置由当前导航目标确定。

全局主题中的“暂停环境动效”控制环境装饰；加载、进度与任务动画继续由各自演示控件管理。系统减少动态效果偏好停止装饰循环并直接切换尺寸和滚动位置。字体选择即时作用于导航、正文、示例与浮层，正文与标题分别读取 `--aig-font-family` 与 `--aig-font-display`，代码区读取 `--aig-font-mono`。

窄屏保留四类顶部导航、全局主题、搜索与折叠目录；示例采用单列布局，表格与代码局部滚动。全局主题复用组件库 Drawer，支持 Escape 关闭、焦点返回与小屏内部滚动。Ctrl / Command + K 聚焦搜索，跳转链接可直接进入主要内容。

## 维护与验证

- `catalog-model.tsx` 组织用途目录并复用 Story；`examples.tsx` 提供交互场景；`scripts/preview-catalog.mjs` 同时收集组件、AI 组件与主题层的 `preview` 导出。
- `brand-controls.tsx` 在顶部抽屉中集中管理全局展示选项与对应接入代码，字体预设与自定义字体栈由 `resolveFont` 统一转成 Provider 属性；组件文档聚焦自身示例、API 和使用说明，主题作用域作为组件文档提供。
- `scripts/component-api.mjs` 为预览与发布共用的源码读取器，包含基础交互属性和同文件公开数据类型。
- 组件说明来自各自 README；代码展开、滚动与文档排版位于预览入口和 CSS。

浏览器检查先按[构建与分发](../engineering/distribution.md)准备 tarball 与消费环境。执行 `pnpm lint`、`pnpm typecheck`、`pnpm exec vitest run --maxWorkers=2`、`pnpm build` 和 `pnpm build:preview`；浏览器回归使用 `pnpm exec playwright test --workers=2`。最新检查结果见[实施进度](../progress.md)。
