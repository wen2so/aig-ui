## 本轮控件扩充

原清单的 21 项控件已提供源码、样式、类型、公开子路径、README 和可运行示例。

- 布局：Flex、Space、Grid、Layout、Splitter。分隔面板支持横纵方向、比例上下限、指针拖动和键盘操作。
- 导航：Steps、Anchor。分别提供步骤状态与文档章节定位。
- 数据录入：InputNumber、DatePicker、TimePicker、Slider、Upload、TreeSelect、Cascader。上传支持校验、进度、取消、移除与重试，过期回调不会恢复已移除项。
- 数据展示：Avatar、Tree、Statistic、Timeline、Image、Segmented。树焦点与选择分离，支持方向键、展开收起和文字定位。
- 反馈：Popconfirm。异步执行期间阻止重复确认和关闭，失败保留弹层并允许重试。

日期和时间采用原生单值输入，不转换 UTC；树及层级选择器当前为单选，上传请求由宿主提供。完整边界见[组件分类与选用](guides/component-catalog.md)。本库名称与 Ant Design 对齐用途，不承诺 API 对等。

## 统一组件设计

以 Button 的直角、精密细线、局部激活和稳定内容为基准，统一通用控件、浮层和 AI 组合的边界。圆角 Token 默认归零，输入、菜单、树和分段选择共用珍珠白交互表面。单选点和旋转加载保留功能所需的圆形。品牌色与危险、成功等语义色独立。

密度改由作用域变量控制，内层 AigProvider 继承外层配置，显式覆盖保留局部效果。普通阅读内容保持静态，按钮的刻面、三个等距亮头、收回续播和高速融合保持原有行为。规则见[视觉语言](design/visual-language.md)。

## 预览工作台

首页提供用途分类、中文和别名检索、网格/列表切换以及按钮、视觉样板、AI 场景入口。详情按组件加载真实示例、源码、API 和说明；说明位于操作区上方，每个示例独立重置与复制。Button 的外观、颜色、尺寸、状态和动效分开说明。

站点外壳与局部示例样式分文件维护，删除原有重复布局覆盖。目录顺序由 component-groups.ts 维护，验收读取同一控件清单。新增或移除源码会使开发服务的 API 缓存失效，缺失 API 不再静默显示空表。
