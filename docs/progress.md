## 2026-09-14 按钮悬停随机闪切（最新）

首次入场和每次鼠标移入随机抽取 1～2 块三角，并生成出现时刻与持续时间。选中的切片各硬切闪现一次，其余保持隐藏，整轮最多 480ms，持续悬停时播放一次并收回。实现复用浏览器动画时间轴，保留宿主指针事件与取消行为，按钮公开 API 保持稳定。Button README、动效规范、视觉风格说明与预览文案已同步。

## 2026-09-13 按钮参考校正（前一轮）

已核对[原文](https://zhuanlan.zhihu.com/p/572806533)及三个按钮入场动图。三角闪切对应控件入场；此前悬停、选中与加载期间常驻的斜线与参考含义存在偏差。本轮改为四块共边的实心三角拼合矩形衬底，600ms 内完成入场并收回，文字与图标保持稳定。Button、IconButton、CopyButton 继续复用同一实现与公开 API。

每次鼠标移入重播三角切片，600ms 内收回；持续悬停时播放一次。悬停和聚焦同时使用边框扩展与单次扫描，按压使用内收与回位，选中和展开保留标记与底线，加载使用专用图标与持续扫描。禁用、减少动态效果与环境暂停展示稳定形态。预览复用现有重置入口重播入场。

验证已完成：Lint、TypeScript、相关文件格式检查通过；24 个测试文件的 74 项单测通过；按钮、预览与组件反馈三个浏览器套件共 19 项通过，覆盖一次入场、持续选择、加载恢复、键盘、360px 长文字、环境暂停、减少动态效果和强制颜色。组件包与预览生产构建、50 项组件资料和 5 项 Registry schema 校验通过。首轮并行检查出现 API 测试超时和交互时序失败，控制并发并隔离平滑滚动后复跑通过，测试断言保持完整。

入场连续帧与窄屏样张保存在 `artifacts/button-reference-fix/`。本轮验证当前源码与构建，独立 tarball 消费、Safari 和人工屏幕阅读器检查继续沿用发布验收流程。以下条目保留为历史记录，当前按钮规则以本节与 Button README 为准。

## 2026-09-13 按钮族重构：直线注记语言（前一轮）

用户复核认为按钮"不灵动、太烂大街"，并点名四角拐角线过于普遍。核验确认旧实现：唯一运动是 14 秒一圈的恒定巡行（实测约 25.7°/s），不承载状态；五个层级背景全透明、圆角相同，只靠线色与字重区分（primary 文字对比度 5.66:1，反而比 outline 的 12.07:1 更浅）；按压反馈只有 1px 内缩。本轮按《底特律：变人》的界面语言重做 Button / IconButton / CopyButton 家族：只用直线与直角，取消角标、弧线与环形轨道，改用"注记框 + 三角标记 + 扫描光带"；API 不变。

| 项目 | 当前结果 |
| --- | --- |
| 轮廓结构 | 按钮本体是一条三角带：少数几个不规则的大三角楔（一道 Λ 加一道斜刻面，SVG 掩码双图层、`auto 100%` 随尺寸缩放），底边闭合、楔间平整、不做锯齿；primary 带端部刻线，secondary 双横轨、ghost 基线不画带，danger 危险色加重底线 |
| 静止与待机 | 扫描光带沿基线驶过后驻留（6.4s 周期）；禁用保持静态等价轮廓 |
| 悬停与聚焦 | 三角带以闪切明灭两步接入到运行亮度（0→0.9→0.25→0.9→0.7，260ms；静止时隐藏）；光带把基线读一遍（460ms，`--aig-motion-scan-duration`）；内容左侧的操作三角以闪切硬切接入（不占布局、不移动文字）；键盘 Tab 获得同样反馈 |
| 闪切 | 闪切发生在三角带本身：悬停时整带明灭两步接入、整框明灭两下（260ms，延迟 90ms）、操作三角两步明灭；按压时三角带闪现一次（180ms）；单次交互明灭不超过两步，不做持续闪烁 |
| 按压与选中 | 线框 90ms 内收、松开 300ms 弹簧回位；`aria-pressed` / `aria-expanded` 保持三角带接入亮度、操作三角常亮并保留加厚底线 |
| 加载与结果 | 三角带保持组装亮度，光带沿基线持续扫描（1.7s 一遍，复用 `--aig-motion-sweep-period`）；复制成功/失败以结果色扫描一次，对勾继续描画 |
| 对比度 | 结构性边界满足非文本 3:1：primary 边框约 4.3:1、outline 3.4:1、secondary 3.2:1、danger 约 4:1 |
| 工程检查 | ESLint、TypeScript、Prettier、24 个文件 74 项单测通过；Token 由 `scripts/tokens.mjs` 重新生成 |
| 浏览器检查 | button-motion 3 项通过（含四角闭合、三角标记、按压键程、端封与减少动态效果的新用例）；预览相关全量套件 35 项全部通过（此前记录的对话锚定偏差与描边时序抖动本次复跑未复现） |
| 文档同步 | 视觉风格定义的按钮族与运动分配、动效规范的按钮交互补充、Button README、预览示例说明已更新 |
| 待办 | 全量 Chromium 与独立消费矩阵随下一检查切片重跑；用户视觉确认 |

本轮目视核对覆盖静止、悬停闭合、按压、加载扫描、复制成功、各层级特写与减少动态效果形态，最终样张位于 `artifacts/button-refresh/`。分页等其他仍在使用角标与环形轨道词汇的组件保持原样，按试点范围留待下一轮。

## 资料与升级

组件就近 README、Props/JSDoc 和实际 Story 是文档真源。构建生成 manifest、按组件拆分的 API/说明、源码快照、可编译示例、llms 索引与版本化 Registry。manifest 标记 experimental，并记录 sourceCommit、sourceDirty 和 sourceSha256。

Registry 分发页面源码，基础实现仍来自同版本 aig-ui 包。升级页面时将新版本安装项提取到临时目录，与本地已修改页面进行 diff 后合并；业务回调和本地布局保留。当前独立消费检查使用 Registry JSON 的真实内容，公开 shadcn CLI 安装链在 npm 版本和公共地址发布后验证。
