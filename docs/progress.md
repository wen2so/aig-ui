- 按钮首次交互才创建边缘轨迹及浅色副本。200 个静止按钮的矩形节点从 20,800 个降为 0，刻面与遮罩保留原有行为。尺寸、内容和动效观察器仍按实例维护。
- 测试按预览、动效和独立消费拆分，CI 新增 Firefox 与 WebKit 关键流程。体积按实际安装包与预览静态依赖检查，增长超过基线 10% 时失败。性能数据和口径见[性能测量](engineering/performance.md)。

## Button 边缘循环

边缘线默认隐藏且不运行动画；hover 或键盘聚焦后显示三个等距亮头与后向渐隐尾迹，离开后用 3 秒减速收回，并保存停止位置供下次续播。亮头缩细到 0.55px，尾迹为 0.15–0.48px；持续悬停约 8 秒后逐渐融合为 0.5px 均匀光边，移动线段完全淡出，避免高速时仍出现明暗绕行。动态线条最高不透明度为 32%，光晕颜色混合强度上限为 45%；加速度平滑趋近每秒增加 7 倍速。ghost 默认与选中状态均无底线。光晕和内部燃烧渐变跟随品牌色或语义色。outline 与 ghost 使用不透明珍珠白（#f5f3ee）交互填充，避免浅色背景上难以辨认，且语义色仅影响文字和边缘，保持原色文字，燃烧集中在边缘。未激活、加载与禁用状态不主动启动边线，减少动态时静止。本轮 TypeScript、专项 ESLint 通过；12 项 Chromium 动效用例分批通过，加速用例按更早进入融合的时序更新后复跑通过。覆盖完整收回后的续播及浅色副本同步、高速均匀光边、无填充文字与语义颜色跟随、ghost 默认与选中状态无底线。真实 Safari/iOS 与人工视觉验收尚未执行。

## Button 参考动图重建

当前拼块使用统一三角网格，基础平行四边形的上、下边与单个三角形底边等长。保留原始块归属：三个单元组成的梯形合并为一个绘制面，只整体显现与收束，其内部不独立闪切。每个采样点随机点亮至多两组独立三角或平行四边形，组间至少留两个空单元。块面与文字遮罩取消描边，在隔离底色层中累加共边覆盖率，消除中间帧及半透明阶段的深浅接缝。挂载与首次交互各播放一次，后续 hover、键盘聚焦和加载恢复直接显示对应状态。字体、尺寸与换行变化按当前种子适配网格；减少动态效果时保持静态。

几何检查覆盖 5 种宽高、每种 32 个种子，验证完整覆盖、统一斜率、基本边长和同源块合并；64 轮采样检查组合多样性、同种子复算，以及梯形归属、分组长度和组间距。浏览器检查首次交互与后续进入、40ms 边界硬切、梯形整体显现和文字遮罩；接缝回归在 1×、2× 像素密度与小数宽度下读取真实截图，检查 280ms 满亮和 880ms 半透明阶段的底色、遮罩。已更新首次、再次与第三次进入的截图，真实 Safari/iOS 与用户视觉确认仍待完成。

已将用户提供的 600×338 WebP 拆为 67 帧（每帧 40ms、总长 2680ms），逐帧查看并生成本地查看器。组件接入 1000ms 时间线、120ms 行内错峰、前段硬切与后段淡出，选中项保留实底；主操作改为直角和外围短标。新增 `entrance` 开关与“菜单入场与选中”演示，品牌衬底改用 accent。拆解记录说明实测画面、重建参数与未展示的交互边界，见[参考拆解](design/button-reference.md)。

本轮 3 个按钮族测试文件的 8 项单测、6 项 Chromium 浏览器回归、TypeScript、定向 ESLint 与 git diff --check 通过。组件构建、50 项组件资料及示例类型、5 项 Registry 校验和预览构建通过。浏览器按时间点采样验证整帧跳变、后段连续过渡、遮罩同步、选中保持、方形图标边界、键盘、窄屏与减少动态效果；逐帧查看器已核对 F011 / 440ms 的原图及裁切。原作逐像素一致性、真实 Safari/iOS 和读屏、用户视觉确认仍待验收。预览主 JS 为 1121.79kB，保留已有的大文件提示。

AI 复用验收覆盖品牌启动、提前就绪、失败重试、访问状态、保存表单、筛选为空、详情抽屉、消息流、阅读位置、来源展示、产物审核和窄屏长文本，记录模型与文档版本、首次结果、修正次数和人工介入。
