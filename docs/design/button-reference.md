# Button 参考动图拆解

更新日期：2026-09-16。

## 素材与证据

来源为李世钦的[《从〈底特律：变人〉看严肃科技风格的动效设计方法》](https://zhuanlan.zhihu.com/p/572806533)，配合用户提供的 `v2-1897d7673ca0bb16ca928dc2ea09c94d_b.webp`。文章讨论按钮衬底的三角闪切，以及直线、矩形与平行四边形的配合。本次具体时间、几何和状态判断来自本地动图解码。

Pillow 实测：600 × 338px，67 帧，每帧 40ms，总时长 2680ms。帧编号从 F000 开始。重点观察区域为 x=0–600、y=178–280；第一条衬底约为 x=42–175、y=193–216，宽高比约 5.8:1。测量允许约 1–2px 的压缩边缘误差。

运行 `python scripts/analyze-button-reference.py <源文件路径>`，在 `artifacts/button-reference/` 生成完整逐帧 PNG、两倍按钮裁切、四张连续帧联系表、关键帧图、`timing.json` 和 `index.html`。查看器支持上一帧、下一帧、拖动、原速和 1/4 速度，逐帧记录覆盖全部 67 帧。源图片不随组件包分发。

## 设计构成与原实现差距

| 维度 | 参考中可观察到的行为               | 修改前的 Button                     | 本次落实                                                   |
| ---- | ---------------------------------- | ----------------------------------- | ---------------------------------------------------------- |
| 触发 | 整组界面入场                       | 初始静态，仅首次 hover / focus 播放 | 挂载入场与首次交互各播放一次，后续进入直接高亮             |
| 节奏 | 前段明显的有／无切换，后段持续变浅 | 主体用 cubic-bezier 插值明灭        | 前段 `steps(1, end)`，后段局部 `linear`                    |
| 块面 | 少量宽阔主体、斜带与三角缺口       | 4 / 5 块宽度较均匀的随机刻面        | 保留组合块归属，梯形整体显现与收束，独立三角和平行四边形随机闪切 |
| 编排 | 前几项先后建立，持续阶段有重叠     | 各按钮等待各自交互                  | 同一批挂载按视觉行排序，行内间隔 120ms，行间并行           |
| 收束 | 第一项保留深色，其他项底色退去     | 悬停保持，选中只有底线与标记        | `aria-pressed` / `aria-expanded` 驱动持续底色              |
| 轮廓 | 直角细长横条、外围短标             | 带圆角的完整框线、框内装饰线        | 直角；primary 用四个外围短标；outline 继续承担完整边框层级 |
| 明度 | 深底浅字，空白处深字               | 品牌高亮与白色混合，整体偏浅        | 品牌衬底使用 accent，文字与细线按实际可见面遮罩切换        |

文字在块面切换时保持位置稳定。运动作用于衬底和辅助线，不移动按钮的点击区域。三角和斜带既作为出现的块面，也作为暂时缺失的区域；仅把多块色面同时渐显无法形成这种节奏。

## 组件时间线

单按钮使用 1000ms 时间线。独立块在 80–120ms 低亮预闪，240ms 局部出现，280ms 短暂补齐，360–600ms 每 40ms 更换一次组合，600–760ms 连续补回。梯形与边缘主体在 120–280ms 统一显现、保持至 760ms，不进入随机闪切。760–1000ms 所有块收束到实际状态。同一行相邻项增加 120ms；最大延迟为 360ms，四项整组最长 1360ms。宽工具栏的后续项目共用最大延迟，避免等待持续增长。

这是一组面向组件的重建参数。它复用参考的阶段关系，没有逐像素复刻每个菜单项不同的遮罩和切换序列。参考能确认亮块组合切换，无法由这段单次入场录像确定原作每轮是否随机生成分区。

按钮先用三角网格建立原始块：两个相邻单元组成平行四边形，三个组成梯形。每个单元保留所属原始块；同一梯形拆出的单元不参与独立闪切，渲染时合并为一个完整多边形，只统一显现和收束。独立三角和平行四边形以原始块为单位随机选取，每帧至多亮起两组，两组之间至少保留两个网格单元的距离。梯形保持完整，不因其内部三角或平行四边形的显隐出现缺口。

块面与文字遮罩均取消额外描边，几何轮廓随填充显隐，避免半透明描边叠深。同源多边形合并为一个绘制面；不同块的共边使用 `plus-lighter` 累加抗锯齿覆盖率，底色层单独隔离，避免共边像素按普通透明叠加产生浅色细缝。闪切、半透明收束与稳定高亮使用同一合成方式，文字遮罩同步处理。按钮外围四段装饰短线沿闭合矩形边缘缓慢循环，默认每圈 48 秒，线长独立随机并降低默认亮度；悬停在 900ms 内平滑加速至 3 倍，离开后恢复，浅色副本同步循环进度，减少动态时静止。

每轮随机确定网格的整体横向偏移、上下朝向、原始块分组与采样表，一轮内归属稳定、独立块的亮起组合变化。通常按实际高度构造 60° 斜边，紧凑按钮统一加陡；超出按钮的边缘单元直接裁切，不改变内部单元形状。普通重渲染复用当前种子；字体、宽度与换行变化使用同一种子适配网格和组合，保留已有节点与播放进度，增减文字遮罩以匹配实际绘制面数量。

`entrance` 默认 `true`，可用 `entrance={false}` 关闭。挂载入场与首次悬停／键盘聚焦分别记录，首次交互可重播一次，后续进入直接高亮，不重新抽取或播放。加载、禁用中断高亮，恢复后保留已交互记录，不自动重播；重新挂载可重置记录。减少动态效果直接显示静态状态，并保留当前分区。业务选择由调用方设置，组件不自动推断第一项选中。

基础平行四边形的上、下边与单个三角形底边等长。设斜边水平偏移为 d，两种水平边长均为 2d，基础平行四边形整体横向占宽为 3d。网格在按钮边缘裁切以覆盖完整底色，裁切单元只参与整面补齐与收束。

## 可确认边界

40ms 是素材采样间隔，无法证明原始引擎也以 25fps 播放，或精确还原采样之间的插值、原始透明度和随机算法。录像包含动态背景和有损压缩，不能把像素颜色直接当作原始 UI Token。

素材展示入场和稳定选择，没有展示完整 hover、移出、点击、禁用、加载与键盘流程。本次保留既有交互约定并做组件化补全。浏览器回归验证实现约束，用户视觉认可与原作像素级一致性分别记录。
