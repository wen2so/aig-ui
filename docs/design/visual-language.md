# 视觉语言

更新日期：2026-09-16。当前方向为暖白留白、精密线绘与局部激活，沿用 `reference/404.html` 的空间、字体和加载叙事。内容保持稳定，线条响应操作，品牌加载承担完整的绘制、协同、撤回与解构。

## 空间与层次

| 层次 | 当前规则                                             |
| ---- | ---------------------------------------------------- |
| 内容 | 正文、标题和操作位置稳定，用字号、字重与间距建立层次 |
| 控件 | 保留清晰主轮廓，聚焦时建立辅助线，状态完成后收束     |
| 容器 | 完整边界与充足内距，卡片和面板聚焦时增加一条短线     |
| 环境 | 暖白径向渐变提供轻微深度，阅读区域保持平静           |
| 品牌 | 200 × 200 SVG、三角描边和反向双环，主题统一配置      |

Card、Panel、Dialog 支持 glass 与 solid 材质。模糊能力缺失时使用兼容表面，强制颜色模式使用系统颜色。容器层次由边界、表面与间距共同表达。

## 字体与颜色

正文和标题沿用参考页的 `Inter, 'Microsoft YaHei', -apple-system, BlinkMacSystemFont, sans-serif`；代码和编号使用 `'JetBrains Mono', ui-monospace, Consolas, monospace`。预览应用本地加载 Inter 与 JetBrains Mono 的字重资源，中文按字体栈回退。主题提供正文、标题和等宽三组覆盖，Portal 继承所属作用域。

品牌色用于主操作，危险、成功、警告、信息和中性由主题语义色表统一配置。危险默认鲜红 `#E60012`，与品牌色分开识别。配置方式见[主题指南](../guides/theme.md)。

## 按钮族

Button、IconButton、CopyButton 共用操作层级，最小高度为 26 / 32 / 40px。

| 层级      | 稳定轮廓         |
| --------- | ---------------- |
| primary   | 三段等距外围线     |
| secondary | 上下横线         |
| outline   | 连续细框         |
| ghost     | 基线，悬停时延展 |
| danger    | 危险色边界与底线 |

挂载时播放一次错峰入场。单按钮 1000ms，同一批按钮按视觉行排序，行内间隔 120ms、最多延迟 360ms，行间并行。首次悬停或键盘聚焦可重播一次，后续进入直接稳定高亮；普通重渲染和加载恢复不重置交互记录。`entrance={false}` 可关闭入场，目录缩略图保持静态。

按钮以三角网格建立原始块：两个单元组成平行四边形，三个组成梯形。保留各单元的块归属，渲染时合并同源单元；梯形内部不独立闪切，120–280ms 作为完整主体显现、保持至 760ms。独立三角和平行四边形随机闪切，同一帧至多点亮两组，组间保留至少两个网格单元的距离。80ms 低亮预闪，240ms 局部出现，280ms 补齐，360–600ms 按 40ms 帧格更换组合，600–760ms 独立块补回，760–1000ms 统一收束。所有斜边共用同一偏移，常规角度为 60°，紧凑按钮统一加陡。选中或展开项保留完整底色，其他项回到透明。

基础平行四边形的上、下边与三角形底边等长，均为斜边水平偏移的两倍；其整体横向占宽还包含斜边偏移。边缘裁切单元只参与完整底色的补齐与收束。

按钮使用直角，primary 通过三段等距外围线定位，outline 保留完整框线。品牌衬底使用 accent，语义衬底使用对应语义色。块面与遮罩不额外描边，轮廓随填充显隐；同源多边形合并，不同块在隔离层内累加共边覆盖率，消除闪切和半透明阶段的浅色细缝。文字、图标和细线按可见面同步显示浅色，稳定后保持相同的合成方式。三段外围细线沿闭合矩形边缘缓慢循环，默认每圈 48 秒、不透明度 18%，三段按周长的三分之一等距排列，初始线长为周长的 3%，随速度同步增长，49 倍速时闭合（从默认速度开始持续悬停约 13 秒）为完整边框，拐角连续折转；悬停期间持续平滑加速，不设速度上限；线条亮度和三层由冷蓝转向橙金的光晕随实际速度增强，离开后在 3 秒内平滑减速，线条逐渐缩短、光晕逐渐减弱，恢复默认状态，减少动态时静止。

逐帧证据、重建参数与录像无法确认的交互边界见[Button 参考动图拆解](button-reference.md)。

左侧标记表示悬停、聚焦、选中或展开。按压使边框收拢，松开回位；加载显示专用标记并扫描基线，禁用保留稳定轮廓。方形 IconButton 保留方形操作边界。

## 运动分配

| 组件族           | 稳定状态         | 操作反馈                       |
| ---------------- | ---------------- | ------------------------------ |
| 输入与检索       | 完整细线边界     | 聚焦基线延展，错误使用语义色   |
| 选择与分页       | 轮廓和当前选择   | 对勾建立、核心入位、滑块平移   |
| 导航与页签       | 稳定位置指示     | 指示线延展、内容进入           |
| 卡片、面板与浮层 | 边界、表面与留白 | 聚焦短线、浮层进入与退出       |
| 加载与任务       | 就绪时静态       | 工作期间持续描边、扫描或旋转   |
| AI 阅读区域      | 消息和轨道稳定   | 生成或执行中启用对应节点与轨道 |

普通组件的静态阅读保持平静。LoadingMark、LoadingSequence、未定进度、骨架屏、忙碌按钮及进行中的任务保留运动。品牌加载仍按描边建立、双环协同、反向撤回、表面解构、内容接入的顺序交接，具体时间线见[加载与动效](../guides/motion.md)。

减少动态效果偏好提供静态等价状态，强制颜色模式保留系统边界与状态。折叠内容按实际高度连续展开，目录定位保持平滑滚动和浏览器历史。

## 预览与验收

总览使用静态缩略图，组件详情展示实际交互。加载舞台扩大留白，演示控制位于舞台外。视觉样板组合输入、卡片、主次操作、危险操作、确认浮层和加载交接，用完整任务评估信息主次。

同一视口、品牌与状态下记录“已符合、部分符合、差距明显”。按钮检查首次交互、重复交互、刻面深度、线条对比与边缘连续；整页检查静态阅读和加载交接。同步核对键盘、禁用、长文字、窄屏、减少动态效果与强制颜色。用户视觉确认与自动化结果分别记录，范围见[项目状态](../progress.md)。

## 图标来源

操作、导航、选择与结果图标统一使用 Lucide，通过 Icon 保持尺寸、描边与装饰语义。图标按钮以 `aria-label` 提供名称。品牌标识、刻面、边缘装饰与 LoadingMark 属于品牌图形，沿用既有设计。

原生复选框使用 Lucide Check、Minus 生成的 CSS 遮罩，`pnpm tokens` 同步资源。普通图标默认 1.5px 描边，小尺寸选择标记采用 2px。

边缘循环线独立于按钮品牌色和语义色：未被刻面覆盖时使用主题正文中性色，刻面覆盖处使用白色线芯，光晕从冷蓝色随速度升温为橙金色，按钮内部同步显现暖色渐变，hover 即有基础光强，随后随速度继续增强；hover 线芯为 2px、至少 90% 不透明度，轨迹向内留出 2px，避免白色线芯被遮罩裁掉；光晕分为贴线、近处扩散和外围柔光三层，最大模糊半径为 2px、7px、16px；速度继续增强光晕和剩余亮度。
