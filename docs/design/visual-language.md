# 视觉语言

更新日期：2026-09-14。当前方向为暖白精密线绘，参考原始品牌加载的描边叙事和精密界面的空间层次。每个元素对应边界、操作或状态，丰富程度来自线条协同与交互变化。

## 分层与颜色

| 层次 | 当前规则                                                  |
| ---- | --------------------------------------------------------- |
| 内容 | 文字、实际操作图标与阅读位置保持稳定                      |
| 控件 | 细线边界、基线、刻度和状态标记围绕操作区域组织            |
| 容器 | 柔和玻璃或实色表面，贴边括角、侧轨和中轴刻线组织空间      |
| 环境 | 暖白背景、网格与光带提供页面层次                          |
| 品牌 | 200 × 200 SVG、哑光玫瑰装饰和深玫瑰强调色，可通过主题替换 |

玫瑰是默认装饰色相，成功、警告和危险继续使用语义颜色。保留的 signal Token 用于兼容宿主覆盖。字体由主题的正文、展示、等宽三组 Token 控制，浮层跟随所属作用域；字号和字重仍按组件层次组织。

Card、Panel、Dialog 默认使用 glass，solid 提供实色表面；模糊能力缺失时使用兼容表面，强制颜色模式使用系统颜色。品牌与字体配置见[主题指南](../guides/theme.md)。

## 按钮族

Button、IconButton、CopyButton 共用边框、端部刻线与基线扫描，最小高度为 26 / 32 / 40px。

| 层级      | 稳定轮廓                 |
| --------- | ------------------------ |
| primary   | 矩形细框加端部刻线       |
| secondary | 上下双横轨               |
| outline   | 连续矩形细框             |
| ghost     | 带端封的基线，悬停时扩展 |
| danger    | 危险色边界与加厚底线     |

静止态呈现细框和每 6.4s 巡行的基线光带。横向按钮悬停或键盘聚焦时，由四边形与单块三角形混合的刻面组成高亮表面，共用边界直接拼接，斜边分组转向、块面宽阔。形状舒展、粒度适中，作为一片完整亮面表达激活状态。

每个按钮挂载时生成 4 或 5 个三角形与四边形刻面，结构和三档配色在本次挂载期间固定，hover 和状态切换复用原有刻面。端部采用梯形贴边收口，各色块均贯穿按钮高度，采用共享直线边界直接拼接，避免半高色块单独消失、共同焦点与连续锯齿。品牌色刻面使用 0.88、0.94、1.00 三档不透明度。

页面就绪后各行同时开始，行内从左到右错开 140ms。每轮约 40% 刻面参与闪切，按总数四舍五入：4、5 块均选 2 块。快慢节奏交替，参与闪切的刻面在约 0.47–0.80 秒陆续稳定；其余刻面单次显现。整轮最长 800ms，刻面采用连续缓动完成两次明灭，浅字透明度同步跟随，整轮结束时进入终态。首轮结束后收回，hover 或键盘聚焦重播后保持高亮，移出或失焦时收回。

三角形与四边形刻面以 64% 品牌色混合全局表面色绘制，按钮底保持透明，刻面外沿与框线同步展开和按压回位；文字与图标以深色为底，hover 和键盘聚焦时浅字随刻面透明度逐区域渐入，淡出处恢复深字；首轮自动闪切保持深字；危险状态继续由危险色边框与底线表达。左侧固定三角表示悬停、聚焦、选中或展开，与高亮面的闪切分开表达。选中和展开保留标记及加厚底线。方形 IconButton 使用正方形轮廓，高亮面隐藏。

按压使边框收拢，松开回位；加载显示专用图标并持续扫描基线；禁用按钮保留静态轮廓。减少动态效果时直接显示稳定高亮和实际状态，强制颜色模式使用系统边界与选中色。

## 其他组件的运动分配

| 组件族           | 持续运动                   | 交互过渡                     |
| ---------------- | -------------------------- | ---------------------------- |
| 输入与检索       | 基线、页边巡线与刻度       | 聚焦延展、错误边界           |
| 选择与分页       | 轨道、节点与刻线           | 对勾建立、选择核心、滑块平移 |
| 导航与页签       | 边线与位置节点             | 指示线延展、节点入位         |
| 卡片、面板与浮层 | 括角、侧轨、中轴与边缘巡线 | 进入、退出与位置交接         |
| 加载与状态       | 反向双环、描边和进度扫线   | 撤回、解构与内容交接         |
| AI 组件          | 阅读边线、任务轨道与节点   | 消息更新、确认与产物切换     |
| 文字与阅读列表   | 稳定排版                   | 保持内容可读                 |

Input 使用基线刻度，Textarea 使用页边线与横格，Select 保留四角括线，Combobox 保留缺角结构。分页、选择器、卡片与浮层仍使用各自既有轮廓；后续修改先核对当前状态页的视觉待办。

折叠面板按实际高度展开与收拢，代码区使用连续高度过渡。目录定位使用平滑滚动，地址直达与浏览器历史保持一致。

## 动效与阅读

环境运动通过恒定亮度的线条移动表达，有限状态切换保留淡入、位移、收拢和展开。外环默认 14s、内环 7s、巡航 6.4s、扫描 460ms。具体加载时间线见[加载与动效](../guides/motion.md)。

完整效果默认开启，系统减少动态效果偏好提供静态等价表现。预览环境暂停控制装饰，加载和任务演示由各自控件管理。轨道与刻线沿实际边界组织，为文字和操作保留稳定空间。

## 视觉验收

每次视觉修改提供相同视口、品牌、状态下的对照，记录“已符合、部分符合、差距明显”。按钮至少展示静止、闪切组装、稳定高亮与退出；实际播放核对节奏，静态样张核对形状与层次。

同时检查键盘聚焦、禁用、加载、长文字、窄屏、减少动态效果与强制颜色。品牌和字体覆盖检查普通控件、加载序列与 Portal。用户视觉确认与工程自动化结果分别记录，当前边界见[项目状态](../progress.md)。
