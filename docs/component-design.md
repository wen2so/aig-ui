# 组件视觉用法

方案 2.0 的本地修正版采用暖白环境、暖玫瑰几何和精密信息层级。当前状态为 experimental，运行样张可供审阅，用户视觉确认单独记录。

Card、Panel、Dialog.Content 默认使用 glass；Drawer 继承 Dialog.Content 的材料选项。material="solid" 用于需要实色阅读面的场景。AigProvider 默认 glass，显式 solid 统一使用实色兼容表现。玻璃采用 155deg 三段渐变、46px 模糊、155% 饱和度与六层阴影；模糊不可用时保留实色底。forced-colors 使用系统表面和边界。

宿主导入 aig-ui/styles.css 后，输入面、选择浮层、状态轨道、数据排版和主要容器共享 Token。页面配方的 aig-brand-scene 类提供环境径向光、44px 网格和 12s 光带，保持内容自然滚动。正文使用自然字距，数字与版本使用等宽数字；装饰色和功能文字色分别维护。

品牌初始化采用 LoadingSequence，并导入 aig-ui/motion/styles.css。完整绘制后，旧标签在 180ms 内退出，横线和三角分别撤回 720ms 与 980ms；表面从 720ms 开始消散，内容从描边撤回结束后进入。提前就绪按实际描边缩短等待。短暂局部操作采用 Button loading、Spinner 或 Progress。

AI 界面同时导入 aig-ui/ai/styles.css。消息、输入、工具和产物使用稳定阅读底，任务步骤、来源序号和版本提供精密信息层级。草稿、停止、重试、来源和版本确认沿用业务回调，演示数据由配方明确标识。

所有动画遵循系统减少动态效果偏好。正常环境保留完整材料和动画；颜色与尺寸通过公开 Token 调整。CSS 时长变量控制循环动画，有限 WAAPI 时长由同源生成的常量控制，CSS 覆盖不会改写有限编排。

组件说明与可编译示例位于同版本 components 和 examples 目录；manifest.json 列出准确路径。视觉基准确认、真实辅助技术、真实业务及公开发布继续按交付记录验收。

2026-09-12 补充方向：全部组件采用更鲜明的《底特律》式精密科幻语言。暖玫瑰保留品牌身份，低饱和冰蓝信号线贯穿边缘坐标、分段轮廓、菱形节点、弧形轨道与输入激活线。结果和空态共用多层 SVG 状态图形；容器边线分段建立，忙碌状态与流式消息维持活动反馈，完成结果回到静态阅读。
