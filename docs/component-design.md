# 组件视觉用法

2026-09-12 最新修订：线条围绕控件边界运行，按钮内容区承载文字与实际操作图标，选择与聚焦通过外围几何变化表达。每个元素对应明确的空间或状态职责。品牌配置集中在预览顶部“全局主题”入口，接入方式见[品牌自定义](./brand-customization.md)。当前视觉规则见[视觉风格定义](./design-language.md)。

方案 2.0 线框版：页面环境是暖白玻璃，控件是线框仪器。50 个组件与 5 个页面组合已按[视觉风格定义](./design-language.md)完成迁移，当前状态为 experimental，运行样张可供审阅。

## 分层

- **环境层**：页面配方 `aig-brand-scene` 提供暖白径向光、44px 网格与 12s 光带。玻璃与光晕只属于这一层与容器层。
- **容器层**：Card、Panel、Dialog.Content 默认 `material="glass"`，Drawer 继承 Dialog.Content 的材料选项；Popover、DropdownMenu、Select/Combobox 浮层与 Toast 继承全局材质。Card 使用贴边括角，Panel 使用按实际高度约束的侧轨，Dialog 使用中轴刻线，AI 阅读与输入面使用底线。刻线挂载时绘制，停留时沿边巡行，正文拥有独立的安全区。`material="solid"` 提供实色表面；模糊不可用时回退实色。forced-colors 使用系统表面和边界。
- **控件层**：透明底与发丝线保持统一，轮廓按用途区分。按钮使用矩形刻线框、上下横轨、连续细框、端封基线与危险底线；入场三角切片在 600ms 内收回。IconButton 复用同一结构并保持正方形外框。Input 是两端带刻度痕的基线尺，Textarea 是带页边线与横格的记录纸，Select 是四角括线的仪器轮廓，Combobox 保留缺角结构。字段线色通过 `--aig-field-line` 平滑过渡；选择族使用绘制式对勾、圆形核心与选中轨道。控件高度统一为 32px（sm 26 / lg 40）。

冰蓝信号线（`--aig-color-signal`）已从全部默认样式中移除，token 保留以兼容宿主覆盖。玫瑰（`--aig-color-mark`）是唯一装饰色相，深玫瑰（`--aig-color-accent`）用于强调文字。

## 动效词汇

绘制用于对勾、箭头和刻线建立；双向轨道用于加载标记与选择内核；巡线沿输入基线、页边、表头和容器边缘移动。环境运动与交互过渡共同运行：聚焦扩展字段括线，选中建立内核和外轨，页签延展定位线，按压使按钮边线收拢。文字与布局保持稳定，待确认和已完成任务的末节点保持静态语义。系统减少动态效果偏好下直接显示最终形态，静态形状保持完整。分类、交互场景和独立文档入口见[预览指南](./preview-guide.md)。

品牌初始化采用 LoadingSequence，并导入 aig-ui/motion/styles.css。完整绘制后，旧标签在 180ms 内退出，横线和三角分别撤回 720ms 与 980ms；表面从 720ms 开始消散，内容从描边撤回结束后进入。短暂局部操作采用 Button loading（迷你线绘标记）、Spinner 或 Progress。

AI 界面同时导入 aig-ui/ai/styles.css。消息、输入、工具与产物使用玻璃或稳定阅读面，任务步骤、来源序号和版本提供精密信息层级；草稿、停止、重试、来源和版本确认沿用业务回调，演示数据由配方明确标识。

颜色、字体与尺寸通过公开 Token 调整；CSS 时长变量控制循环动画，有限 WAAPI 时长由同源生成的常量控制，CSS 覆盖不会改写有限编排。组件说明与可编译示例位于同版本 components 和 examples 目录；manifest.json 列出准确路径。视觉基准确认、真实辅助技术、真实业务及公开发布继续按交付记录验收。
