# aig-ui 文档

最新交付：50 个组件和 5 个页面组合已完成方案 2.0 的本地代码迁移，并按用户补充要求加强《底特律》式线条和动效。详见[组件迁移记录](./component-migration.md)、[公共视觉用法](./component-design.md)及[本轮验证结果](./progress.md)。下文保留方案编制时的背景与阅读顺序。

`aig-ui` 是 React UI 组件库，采用暖白、柔和玻璃材质与平静动效，支持开发者和 AI 智能体复用。

当前已实现本地实验性 Alpha：50 个组件、5 个页面组合、实时预览和本地打包资料。实际状态见[实施进度](./progress.md)，启动方式见[根目录说明](../README.md)。以下四份文档保留为建设与正式发布的目标基线，文中的排期及未勾选项目按实际验证继续推进。
