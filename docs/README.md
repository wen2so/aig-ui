# aig-ui 文档

最新交付：完成静止与禁用呼吸、组件轮廓分化和预览文档重构，见[预览指南](./preview-guide.md)。此前完成全组件线框迁移——50 个组件与 5 个页面组合统一为「环境玻璃、控件线框、玫瑰唯一色相」的线绘语言，冰蓝信号线从默认样式移除。规范见[视觉风格定义](./design-language.md)，组件用法见[公共视觉用法](./component-design.md)，执行记录见[本轮验证结果](./progress.md)。

`aig-ui` 是具有仿生智能气质的精密科幻 React UI 组件库。以 `404.html` 的暖白环境、几何绘制、协同运行和反向解构为直接参考；《Detroit: Become Human》式的仿生智能气质必须通过这套线绘语言表达，而不是在其上叠加新的装饰。

当前已实现本地实验性 Alpha：50 个组件、5 个页面组合、实时预览和本地打包资料，视觉已按线框语言完成迁移；[视觉风格定义](./design-language.md)是唯一视觉基准。实际状态见[实施进度](./progress.md)，启动方式见[根目录说明](../README.md)。
