## 维护规则

API 以源码类型与公开导出为准，视觉值以 Token 源与实际样式为准，验证结论以注明范围的执行记录为准。修改时同步受影响的指南和就近 README，状态页替换为最新结论。文档只保留当前适用内容，变更过程通过 Git 查询。

`component-design.md` 由构建脚本复制到包内，正文使用可随包理解的路径与说明。新增或移动文档时核对站内链接、预览读取位置和构建输入，生成目录通过脚本更新。
