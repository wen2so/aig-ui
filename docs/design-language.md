# aig-ui 视觉风格定义

更新日期：2026-09-14。当前方向为精密线绘：暖白环境、可替换品牌色、沿控件周边运行的线条与清晰的激活过渡。以《底特律：变人》的精密界面气质和原始 404.html 的描边叙事为参考。每个元素对应边界、操作或状态，丰富程度来自线条的协同变化与空间层次。

## 视觉层次

- 内容层保留稳定的文字、可识别的图标和清晰的操作层级。
- 控件层采用统一细线轮廓，线段沿边缘运行，亮度保持稳定；文字与实际操作图标占据内容区。
- 容器层保留柔和玻璃或实色材质，以贴边括角、侧轨和刻线组织空间；圆弧用于单选、开关和真实加载等具有圆形结构的场景。
- 品牌层通过 SVG、装饰色和强调色配置，默认使用三角线绘和哑光玫瑰。

动效由可见的线条运动表达。辉光呼吸、循环缩放和透明度明灭已从环境装饰移除。状态切换仍保留有限的淡入、位移、收拢与展开过渡。

## 按钮族

Button、IconButton、CopyButton 复用矩形边界、端部刻线与基线扫描。

**三角结构只在交互中出现，静止态不存在。** 静止时按钮是一条干净细线框加一条每 6.4s 巡航一遍的基线光带，表面没有任何三角。参考[《底特律：变人》动效分析](https://zhuanlan.zhihu.com/p/572806533)的做法，三角是交互态的语言，不是常驻装饰。

**悬停时按钮整体高亮，而高亮面本身由三角结构拼成。** 高亮不是叠在三角之上的一层底色，三角面自己就是亮面——选中项变成一条由若干三角面拼合的 bar。三角面由不规则剖分得到：各面朝不同方向张开、面积落在同一量级，面与面之间留细缝，数量约 8 块。**刻意不做上下交错的等腰三角带**，那种排布无论怎么调间距都会读成锯齿，已被否决两次。方形的 IconButton 不参与（横向三角面在正方形上会被压成细条）。

**每个面的明度在每次移入时重新随机分配**，相邻两次悬停的深浅分布都不同。明度同时决定出现时机——越深的面开始越早。每块入场时先硬切明灭三下（亮、灭、亮、沉、稳定），整轮在 600ms 左右收束为完整亮面，全程不经过淡入淡出；出场的节奏要留得住，不能一闪而过。鼠标移出时全部面同时硬切消失。

**悬停同时点亮左侧的固定三角指示**（复用选中态的选择标记位）。它是稳定不动的状态标记，与上面那层"过程性点亮的高亮面"是两件事：前者表示"指针停在这里"，后者是按钮表面的信号组装。选中与展开状态继续保留该指示并加厚底线。

| 层级      | 稳定轮廓                 |
| --------- | ------------------------ |
| primary   | 矩形细框加端部刻线       |
| secondary | 上下双横轨               |
| outline   | 连续矩形细框             |
| ghost     | 带端封的基线，悬停时立起 |
| danger    | 危险色边界配合加厚底线   |

悬停与键盘聚焦扩展边框并扫描基线一次；按压收拢边框，松开回位。`aria-pressed` 与展开状态保留选择标记和加厚底线。加载以专用图标和循环扫描表达，禁用保留静态轮廓，这两种状态不显示三角高亮。减少动态效果和预览环境暂停直接展示稳定按钮。CopyButton 的结果色、完成图标和反馈文字对应真实复制结果。

## 全组件运动分配

| 组件族               | 持续运动                       | 交互过渡                               |
| -------------------- | ------------------------------ | -------------------------------------- |
| 按钮与分页           | 按钮基线光带，分页节点自转     | 三角高亮组装、选中标记、按键内收与回位 |
| 输入与检索           | 基线或页边巡线、刻度           | 聚焦括线延展、错误边界                 |
| 选择控件             | 未选中轨道、节点自转、刻线平移 | 对勾建立、环轨展开、滑块平移           |
| 导航与页签           | 非激活项也保留巡线或节点       | 下划线延展、节点入位、面板进入         |
| 标题、文字与阅读列表 | 稳定的阅读层次                 | 内容保持稳定                           |
| 卡片、面板与浮层     | 贴边括角、侧轨、中轴与边缘巡线 | 进入、退出与位置交接                   |
| 加载与状态图形       | 反向双环、描边绘制、进度扫线   | 完成后连续撤回与解构                   |
| AI 组件              | 内容边线、任务轨道和节点       | 流式状态、确认、恢复与产物切换         |

折叠面板按实际高度展开和收拢，代码区域通过网格高度过渡。文档目录使用平滑滚动，组件切换配合有限的内容进入动画；浏览器历史和地址直达继续生效。

## 节奏、密度与品牌

默认外环 14s、内环 7s、巡航 6.4s、扫描 460ms；禁用按钮保持静态等价轮廓。普通文字与布局尺寸保持稳定，组件按相同运动词汇协作。系统减少动态效果偏好与主动暂停保留静态等价状态，完整动效按默认配置运行。容器括角停靠在边缘，字段括线位于输入内边距之外，图标与文字之间保留固定间隔。

按钮高度为 26 / 32 / 40px，字段高度为 32px。控制圆角、间距、颜色和动效周期继续由语义 Token 管理。

品牌配置与示例见[品牌自定义](./brand-customization.md)。状态色继续表达成功、警告和危险；全局品牌色控制装饰、强调文字、焦点与边界。字体同样属于主题层：正文读取 `--aig-font-family`，标题与展示文字读取 `--aig-font-display`，代码、路径与编号读取 `--aig-font-mono`，浮层与全屏加载跟随所属作用域。字号与字重保持既有层次，换字体不改变排版尺寸。

## 验收

逐项核对静止、禁用、加载、聚焦与减少动态效果状态；确认轨道真实移动、亮度保持稳定、折叠经过中间高度、目录经过中间滚动位置。品牌覆盖需要同时检查普通控件、加载序列与 Portal 浮层。

组件文档包含真实示例、公开属性、默认值、关联类型和使用说明。预览站的品牌、字体、材质、密度与环境动效集中于顶部全局主题入口，主题作用域与 Provider 文档作为组件正文提供。浏览器记录、构建与独立消费结果见[实施进度](./progress.md)。
